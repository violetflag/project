## 1.0.0 (2026-11-03) — 첫 프로토타입
- Selects와 비슷한 영상 편집기: 미디어 가져오기, 대본(받아쓰기)으로 편집, 타임라인, 무음·군더더기 말 정리, 자막, 배경음악, 마커, 되돌리기

- 내보내기: 일반(H.264), Shrink식 고압축(AV1/HEVC), 소리만(WAV)
- 받아쓰기: Whisper(기본), Qwen3-ASR 1.7B(선택, 설정에서 설치)
- AI 편집 에이전트: Claude 계정(구독)으로 연결, API 키는 선택 사항
