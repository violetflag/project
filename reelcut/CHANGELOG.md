## 2.1.0 (2026-11-03) — 전문 편집기 개편

UI·UX 개선 보고서(1.1.0 → 1.2.0 → 2.0.0 → 2.1.0 단계 계획)를 한 번에 반영한 버전입니다.

### 1.1.0 단계: 화면 구성과 조작
- 메뉴 막대(파일·편집·클립·타임라인·재생·보기·도움말)와 단축키 목록 창(Ctrl+/). 메뉴·단축키·목록이 한 명령표에서 나와 서로 어긋나지 않음
- 단축키: I/O(인·아웃), J/K/L 재생, ←/→ 한 프레임, Shift+←/→ 1초, ↑/↓ 편집점 이동, Alt+←/→ 클립 옮기기, Ctrl+D 디졸브, Ctrl+L 소리 분리, Shift+Del 빈칸 남기고 삭제. 한글 입력 상태에서도 동작
- 패널 크기 조절·접기, 작업 화면 탭(편집 / 대본 / 360 / 내보내기), 배치는 PC에 기억
- 편집본 탭(타임라인 위), 아래 상태줄(미리보기·받아쓰기·내보내기 진행, 저장 시각, 인코더)
- 미리보기: 편집본 탐색 막대, 프레임 단위 타임코드(누르면 시간 입력), 전체 화면(F), 안전 영역·3분할 격자
- SVG 아이콘, Pretendard 글꼴 포함, 키보드 포커스 표시, 동작 줄이기 설정 반영, 고정폭 숫자
- 홈: 새 프로젝트 창(용도 16:9·9:16·1:1·4:5·360, fps), 정렬, 빈 프로젝트 정리
- 받아쓰기: whisper VAD(음성 구간 감지)로 쉬는 구간 뒤 단어 시간이 맞고, 무음에 없는 말이 생기지 않음. 이전 받아쓰기는 소리 크기로 단어 시간을 한 번 다듬음
- 고침: 설치된 앱에서 360 미리보기가 검게 나오던 문제(영상이 다른 출처라 WebGL이 읽지 못함)

### 1.2.0 단계: 속성과 내보내기
- 속성 패널을 접히는 묶음으로: 클립·속도·변형·색·소리·전환·360 시점·렌즈. 숫자는 이름을 끌어서 조절, 직접 입력, 초기화
- 변형(위치·크기·회전·자르기·불투명도), 색(노출·대비·채도·색온도·LUT .cube), 잡음 줄이기, dB 표시, 속도 직접 입력
- 360 시점 키프레임: 시점이 시간에 따라 움직임(미리보기와 내보내기 같음)
- 내보내기: ① 용도(유튜브 4K/FHD, 쇼츠·릴스, 인스타, 보관용, 작은 파일, 강의·CCTV, 소리만) ② 화질 ③ 저장. 고급: 비트레이트·소리 비트레이트·fps·소리 크기 맞추기(−14 LUFS)·음악 자동 줄이기(덕킹), 내 프리셋 저장, 인·아웃 구간만, 여러 편집본 대기열, 끝나면 알림

### 2.0.0 단계: 다중 트랙 타임라인
- 트랙: V1 본편(자석식), V2·V3(겹치는 영상·사진, 화면 속 화면), A1(분리한 소리), A2(음악), A3(효과음), C1(자막 보기)
- 트랙 머리: 숨기기·소리 끄기·솔로·잠그기
- 도구: 선택(V)·자르기(C)·편집점 굴리기(N)·내용 밀기(Y), 자석 붙이기(Shift+S)
- 디졸브(클립 사이 ◆), 빈칸, 빈칸 남기고 삭제, 소리 분리(J·L컷), V2로 올리기
- 본편을 고치면 V2·V3·A1·A3가 그 위의 그림을 따라 움직이고 A2 음악은 그 자리에 남음
- 클립에 프레임 줄(필름스트립), 잘릴 무음 미리 보기, 프레임 눈금, 재생 위치 시간 표시, 확대 막대
- 내보내기 엔진: 빈칸, 디졸브(xfade), 변형, 색·LUT, 잡음 줄이기, 360 키프레임, V2·V3 합성, 소리 크기 맞추기, 덕킹

### 2.1.0 단계: 고르기·대본·AI
- 미디어: 썸네일/목록 보기, 정렬(가져온 순·이름·길이·촬영일·별점), 마우스를 올리면 장면 넘겨 보기, 별점(1–5), 고르기(P)·안 씀(X), 태그, 스마트 폴더(고른 컷·3★ 이상·360·대본 있음·안 쓴 것), OSV의 LRF 짝 표시
- 대본: 고른 말이 타임라인에 표시되고 타임라인에서 고른 클립의 말이 대본에 표시됨, 잘린 말 보기와 되살리기, 찾기·바꾸기
- AI 편집: 요청마다 결과 카드(길이 변화, 클립 수, 바뀐 곳 바로 가기)와 "이번 AI 편집 되돌리기". 모델 선택은 설정으로. AI 도구가 트랙·변형·색·디졸브·빈칸·소리 분리를 다룸
