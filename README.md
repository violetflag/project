# Planspace (workspace UI clone)

AI 기획 워크스페이스의 로그인 후 화면 구조와 동작을 재현한 Next.js 데모입니다.
레이아웃, 색상, 글꼴, 메뉴 동작은 참고 서비스의 실제 화면을 측정해 맞췄고,
브랜드 이름, 문구, 이미지는 모두 자체 콘텐츠로 바꿨습니다.

## 실행

```bash
npm install
npm run dev   # http://localhost:3000
```

## 기능

| 영역 | 동작 |
| --- | --- |
| 홈 | 아이디어를 적으면 새 프로젝트가 만들어지고 기획 에디터가 열림. AI 질문 / 내 자료 / 주제 추천 모드 |
| AI 채팅 | 여섯 가지 질문(선택지 + 직접 입력, 답 고치기, 질문 더 받기)으로 범위를 정한 뒤 PRD 생성. "OO 기능 추가해줘", "(기능) 구체화해줘", "검토해줘" 요청 처리 |
| PRD | 문서 구조, 완성도, 항목별 인라인 편집 |
| 기능명세서 | 그래프 / 디렉터리 / 문서 보기, 상태·역할·중요도 필터, 검색, 기능 상세(상태, 중요도, 역할, 근거, 성공 기준, 수용 기준, 코멘트), 기능·묶음 추가와 삭제 |
| AI 수정안 승인 | 채팅이나 검토에서 나온 수정·추가안을 하나씩 또는 한꺼번에 승인·거절 |
| 검토 | 개발, 사업, UX·디자인, QA, 보안, 운영 여섯 관점의 의견, 보류 / 해결 / 채팅에서 해결하기(선택지 카드) |
| 유저플로우 | 기능 묶음별 스윔레인, 시작·페이지·팝업·분기 도형과 화살표 |
| 와이어프레임 | 주요 기능별 흑백 화면 시안 |
| 기획실 | 회의록을 붙여 넣으면 확정·미정·기각 결정을 뽑고, 확정된 결정을 기획서에 반영 |
| 코멘트, 버전 | 기능별·프로젝트 코멘트, 버전 저장과 되돌리기, 작업 로그 |
| 공유 | Markdown, 엑셀(CSV), JSON 내보내기, 클립보드 복사 |
| 프로젝트 관리 | 전체 프로젝트, 즐겨찾기, 휴지통(되살리기, 완전 삭제) |

데이터는 브라우저 localStorage에 저장됩니다.

### AI 연결 (Claude)

왼쪽 아래 [AI 설정]에서 Anthropic API 키를 넣으면, 질문·PRD·기능명세서·검토·채팅 답변을
Claude가 아이디어에 맞춰 새로 만듭니다(`lib/ai.ts`). 홈과 채팅 입력창의 드롭다운에서 고를 수 있어요.

- 모델: Opus 5.5(기본), Sonnet 5.5, Haiku 5.5, Fable 5.1
- 노력: 낮음 ~ 최대 (`output_config.effort`)
- 컨텍스트 크기: 작게(최근 대화 6개) / 보통(20개) / 크게(대화 전체 + PRD 전문)

[내 자료로 시작]에 올린 텍스트·PDF·이미지 파일도 Claude에게 함께 보냅니다(PDF·이미지는 IndexedDB에 보관).
정적 사이트라 서버가 없으므로 키는 방문자 각자의 브라우저 localStorage에만 저장되고 브라우저에서 Anthropic API로
바로 보내집니다. 저장소나 빌드 결과물에는 키가 들어가지 않습니다.
키가 없거나 호출이 실패하면 `lib/generator.ts`의 로컬 규칙 기반 생성기가 대신 만듭니다.

### 구글 로그인 (기기 간 동기화)

왼쪽 아래 [구글로 로그인]을 누르면 프로젝트, API 키, AI 설정이 내 구글 드라이브의 `PlanSpace/planspace.json`
파일 하나로 저장되고(앱이 만든 파일만 볼 수 있는 `drive.file` 권한), 다른 기기에서 같은 계정으로 로그인하면 그대로 이어서 쓸 수 있어요(`lib/sync.ts`).
프로젝트마다 가장 최근에 고친 쪽이 남아요. 드라이브에는 앱을 열 때와 로그인할 때, PRD·기능명세서·검토·유저플로우·와이어프레임이
만들어질 때, 그리고 화면 위쪽 플로피 디스크 버튼을 누를 때 저장해요(버튼의 노란 점은 아직 안 올린 변경이 있다는 뜻). API 키와 AI 설정은 바꾸면 바로 저장해요. 로그아웃하면 드라이브에 저장한 뒤
이 기기에서 프로젝트와 키를 지워요. [내 자료로 시작]의 PDF·이미지 원본은 동기화되지 않아요.
구글 OAuth 클라이언트 ID는 `lib/sync.ts`에 들어 있고(공개해도 되는 값), 빌드 때 `NEXT_PUBLIC_GOOGLE_CLIENT_ID`로 바꿀 수 있어요.

화면 폭이 768px보다 좁으면 휴대폰용 화면(아래 탭: 채팅·문서·검토·더보기)으로 바뀝니다.

## 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 정적 사이트를 만들어 GitHub Pages에 올립니다.
직접 만들려면 `BASE_PATH=/project npm run build` 후 `out/` 폴더를 올리면 됩니다.
