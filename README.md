# Planspace (workspace UI clone)

AI 기획 워크스페이스의 로그인 후 화면 구조와 동작을 재현한 Next.js 데모입니다.
레이아웃, 색상, 글꼴, 메뉴 동작은 참고 서비스의 실제 화면을 측정해 맞췄고,
브랜드 이름, 문구, 이미지는 모두 자체 콘텐츠로 바꿨습니다.

## 실행

```bash
npm install
npm run dev   # http://localhost:3000
```

## 화면과 동작

| 영역 | 동작 |
| --- | --- |
| 그룹 메뉴 | 사이드바 위 카드를 누르면 플랜, 그룹 설정, 멤버 초대, 결제, 그룹 목록 메뉴가 열림 |
| 사이드바 | 홈, 잠긴 항목(프로젝트를 만들면 열림), 연결, 휴지통, 알림함, 즐겨찾기 |
| 홈 | 연결 안내 배지, 인사말, 입력창(AI 질문/내 자료/주제 추천 모드, 글자 수, 전송) |
| 내 자료로 시작 | 파일 끌어다 놓기 영역이 열리고 안내 문구가 바뀜 |
| 연결 모달 | 예시 프롬프트가 3초마다 넘어가는 캐러셀 |
| 업데이트 소식 | 사이드바 아래 카드에서 패치 노트 목록 팝오버 |
| 휴지통 | `/archive` 빈 상태 화면 |

서버 기능(AI 생성, 저장, 알림)은 `lib/mock.ts`의 가짜 데이터로 대신합니다.
브랜드 이름과 사용자 정보는 `lib/brand.ts`에서 바꿀 수 있습니다.

## 디자인 토큰

`app/globals.css`의 `@theme`에 정리했습니다. 기본 글꼴은 Pretendard,
주 색상은 `#845dde`, 본문 `#333`, 테두리 `#e9e8e8`, 캔버스 `#efefef`입니다.
